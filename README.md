# Design-and-Implementation-of-an-Enhanced-Digital-Examination-Timetable
Okemu Blessing Osemudia (Hndswd/24/019) This project is aimed at developing a computerized solution that improves the preparation of examination schedules and assignment of invigilators at FCAHPTIB. The system automates timetable generation, intelligently allocates invigilators based on predefined rules, manages examination venues, balances workload, ensures gender balance and senior lecturer allocation, records attendance and generates reports. It was developed using PHP, HTML, CSS, Bootstrap, JavaScript and MySQL to reduce manual effort, minimize scheduling conflicts and enhance efficient examination management.
